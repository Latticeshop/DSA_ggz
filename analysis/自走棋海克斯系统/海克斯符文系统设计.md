# 海克斯符文玩法规则与内容说明书

> 红警3日冕自走棋（DSA）自定义玩法说明书
> 参考原型：英雄联盟「斗魂竞技场 / 海克斯大乱斗」的三选一强化符文（Augment）肉鸽玩法

---

## 一、玩法一句话

每隔若干回合，全场先统一抽定本次的符文稀有度；每位玩家各自从该稀有度的符文里**三选一**，选中后整局持有。符文在**每回合出兵时**按兵种自动施加到自己的单位上。

符文分三档稀有度：**棱彩（彩）> 黄金（金）> 白银（银）**，档位越高效果越强、也越难抽到。

---

## 二、开启方式

入口在开局「游戏模式」设置里的 **海克斯符文设置**（选项 5）。

| 项 | 规则 |
| --- | --- |
| 发放次数 | 房主可选：**不启用 / 本场一个 / 本场二个 / 本场三个 / 本场四个** 海克斯 |
| 默认值 | 未勾选「开启随机箱子」时**默认不启用**；勾选「开启随机箱子」时一同视为开启，默认 **3 个** |
| 与抽卡的关系 | 「抽卡模式」（选项 4）与海克斯符文设置是**两个独立选项**，互不改写彼此 |
| 重随次数 | 房主可选「**1次**」或「**各1次**」（后者的含义是本次选择中每张卡各限一次） |

> **单人游玩特例**：全场只有 1 名真人时，自动开启**无限重随**。房主一旦手动点过「重随次数」，就按所选的 1 次 / 各 1 次执行，无限重随关闭。

## 三、发放节奏与稀有度概率

| 发放 | 回合 | 棱彩 / 黄金 / 白银 概率 |
| --- | --- | --- |
| 第 1 个海克斯 | 第 3 回合 | 10% / 40% / 50% |
| 第 2 个海克斯 | 第 10 回合 | 15% / 42% / 43% |
| 第 3 个海克斯 | 第 18 回合 | 15% / 42% / 43% |
| 第 4 个海克斯 | 第 27 回合 | 30% / 50% / 20% |

- 次数不足 4 个时**去掉后面的发放**：3 个 → 第 3、10、18 回合；2 个 → 第 3、10 回合；1 个 → 第 3 回合。
- **稀有度由全场统一抽定**：同一次事件里所有玩家面对同一个阶级，各自再按自己的阵营、禁兵种、持有情况筛池。
- 发放发生在回合开始的**备战阶段**，不打断战斗。

## 四、一次事件怎么走

1. **到点提示**：屏幕提示「当前有未选择的海克斯，按'J'键展开面板」。不会自动弹卡页，也不影响战斗。
2. **全图查收**：本次只要有真人入队，就全图播报一次「获得一个海克斯符文，请查收~」。
3. **展开卡页**：按 **J** 打开三选一；面板可反复按 J 收起 / 重新展开。
4. **重随**：每张卡下方有重随按钮，按房主设定的次数使用（单人游玩不限次数）。没有可替换的同阶符文时提示「当前没有可替换的同阶符文。」
5. **点选**：选中后提示「你选择了符文：◇」，并全图播报归属。
6. **生效**：符文整局持有，此后每回合出兵时按兵种施加。

| 情况 | 提示 |
| --- | --- |
| 本阶级可用符文不足 3 个 | 当前阶级可用符文不足 3 个，无法生成选项 |
| 与已持有的符文互斥 | 已持有与【◇】互斥的符文，无法再选。 |

- 同一次三选一里的三个候选**互不重复**；已持有且标记为不可重复的符文不会再次出现。
- 该玩家死亡 / 掉线时跳过，不发放。

## 五、符文的施加规则

### 5.1 只作用自己的单位

默认只强化自己；只有卡面明确写「敌方」的符文才影响对手。个别「全体效果」类符文按卡面为准。

### 5.2 兵种展开

带兵种的通用符文会展开成 **步兵 / 载具 / 飞机 / 海军** 四个独立候选，按当前未被禁用的兵种生成。不同兵种版本可以同时出现在一次三选一里，也可以被同一名玩家分别持有。

- 部分符文只开放部分兵种：如无限火力只开飞机，AT 立场只开载具 / 海军。
- **三档瞄准镜**按兵种各成一张：通用瞄准镜（银）射程 +15%、万用瞄准镜（金）+25%、万能瞄准镜（彩）+50%。
- 任一禁用模式都会移除对应兵种版本（见 §8.1）。

### 5.3 按兵种结算

符文在**每回合出兵时**对新出场的己方单位施加，按兵种分别结算；同一兵种的多张符文叠加在该兵种上，不同玩家的效果互不重叠。

**回合名额**：登神、究极生物这类「一回合只能有一只」的效果共用同一个名额——每名玩家每回合最多认领一只，同一兵种出了两只也只算第一只。

### 5.4 同族先加算再施加

同一效果的**多份先加算、再一次性施加**，不是连乘：

- 两张「大力（兵种）」= `1 + 0.5 × 2` = **×2.0（+100%）**，不是 ×1.5 × 1.5。
- 护甲类符文多份直接在护甲点数上加算（见 §5.6）。

### 5.5 衍生形态同样享受

单位的强化 / 水陆 / 变形形态同样吃到对应兵种的符文，和本体一样结算。

### 5.6 护甲

护甲类共 **5 张**，点数**加算**：

| 符文 | 稀有度 | 护甲 |
| --- | --- | --- |
| 锁子甲 | 白银 | +25 |
| 玄铁甲 | 黄金 | +50 |
| 金麟甲 | 棱彩 | +100 |
| 装甲冲击 | 黄金 | +25，并把护甲值 **1:1** 折成伤害 |
| 泰坦的坚决 | 棱彩 | +25，**全兵种**（每个兵种都吃同一份，只加一次）；禁用兵种时按 100 点总量平摊 |

**换算**：减伤 = `护甲 / (100 + 护甲)`

| 护甲值 | 25 | 50 | 75 | 100 |
| --- | --- | --- | --- | --- |
| 减伤 | 20% | 33.3% | 42.9% | 50% |

- 三张纯护甲符文都可重复获得，点数继续加算，**边际效益递减，永远堆不到 100%**。
- **装甲冲击**：伤害倍率 = `1 + 护甲 / 100`——25 点护甲即 **+25% 伤害**，多份只是护甲继续涨、伤害跟着涨。负护甲同样生效（转为减伤对手视角的增伤）。
- **泰坦的坚决**不带兵种标签，因此四个兵种全都受益。它给的是固定的 **100 点总额**，按当前还开着的兵种数平摊：四兵种 → 每个 25；禁一个 → 3 个兵种各 33；禁两个 → 各 50；禁三个 → 剩下那个 100。这样禁用兵种只是把总量集中到还能出兵的兵种上，不会因为某个兵种的桶空了就凭空少一截。

### 5.7 首发 / 末发限制

| 限制 | 含义 | 涉及符文 |
| --- | --- | --- |
| 本场**第一次正式选择**不下发 | 那时单位池还空着，或过早兑现过强 | 变形重组器、升级重组器、回归基本功、秒速五厘米 |
| 本场**最后一次选择**不下发 | 已无下一次事件可以兑现 | 准备背包、顺手的事、精挑细选、石油佬 |

- 判定「第一次」看的是**这名玩家已经完成过几次正式选择**，与回合号无关：把第 3 回合的事件攒到后面按 J 展开，那一次仍按第一次算。
- 第 3 回合没入队（无建筑）的玩家，其第一次选择同样被拦住。

### 5.8 战场单位存活周期

电脑方（恶魔 / 天使两席）部署到战场的出生单位**默认只存活 4 个回合**，到期在回合开始时清除。

| 项 | 存活回合 |
| --- | --- |
| 常规战场单位 | 4 |
| 奥林匹斯级航空母舰 | 1 |
| 千鸟特攻母舰 | 2 |
| 忒提斯战列舰 | 2 |
| 摇光巡天炮（T4 解锁前 / 后） | 1 / 4 |

- 玩家自己生产、以及符文与箱子**赠送给玩家**的单位不在此列。
- 地图预置的守护神、技能召唤的龙船等豁免（见 §8.3）。

## 七、玩家退出与继承

- **只在同侧继承**：座位 1/2/3 为恶魔侧（面板左列）、4/5/6 为天使侧（右列），只在本侧找承接者。
- **1v1 同侧无人可接**，退出即失去全部符文，该行从面板消失。
- 接手者按座位数继续：3v3 全接手 = 每回合 **3 次**选择，面板三行分别为白 / 金 / 金。
- **未兑现的权益一并转移**：排队未展示的事件、退出时正开着还没点的三选一、准备背包、顺手的事。
- **重随次数不继承**，补进来的那次选择自带一次新的重随。
- 继承来的待选事件排在承接者自己队列之后，一次会连着选好几张（欠账一次补完）。

## 八、与其它系统的关系

### 8.1 禁用模式

禁步兵 / 禁载具 / 禁空军 / 禁海 四个禁用**互相独立、可自由搭配**，最多同时禁用 3 项（全选时自动取消最先选的那个）。

被禁兵种的符文会整张下架，覆盖面包括：

- 四兵种展开版本里的对应版本；
- 声明了兵种约束的赠送型符文；
- 替换型 / 固定兵种型符文（按源单位兵种判定）；
- 兵种对类符文（如元神互锁要求至少 2 个可用兵种）。
- 缩小模式下另有一些符文不下发（如天堂制造）。

**双形态单位**（天狗 / VX / 心神 / 海翼 / 火箭天使等）同时登记在它所有的兵种里，**只有全部被禁才消失**——只禁一个兵种时它照常上场。**超级要塞是例外**，按纯空军登记，只禁空军就剔除。

### 8.2 协议类符文

协议绑定对应阵营的**建造厂**（盟军 / 苏联 / 帝国 / 神州各自对应），**只有基地车不算**；引擎在施放时持续检查持有，所以「授予后再拆基地」不成立。

- **非本阵营**玩家拿到协议符文时，会在地图外补一栋该阵营建造厂当**钥匙基地**，并禁用它的生产与建造页，只保留协议按钮可用。
- 本阵营玩家**抽不到自己阵营的协议**。
- 同一张协议本人只能持有一张；队友各拿一张时各生成自己的钥匙基地（图标重复属正常现象）。
- 被动协议（自由贸易、大生产一类）只解科技锁，不需要钥匙基地。

### 8.3 预设守护神

地图预置的守护神单位**不吃任何海克斯效果**：不加 buff，也不上 debuff。

判定只按对象 id、**不按模板名**，所以玩家自己造的同类单位（如帝国要塞舰、联盟重型坦克）照常吃加成。

## 十、复杂符文详解

### 10.1 登神（黄金）

指定一种兵种，**只保留 1 个**，多余的单位自动回收；每回收 1 个掷一次骰，随机获得一维加成：

| 维度 | 掷中概率 |
| --- | --- |
| 血量 | 40% |
| 伤害 | 30% |
| 攻速 | 20% |
| 射程 | 10% |

- 加成档位按**目标兵种的阶级**取：T1 → 30% / T2 → 40% / T3 → 50% / T4 → 60%。
- 单位体积固定放大 **×1.3**，与掷骰无关。
- 层数**累计不清零**，面板详情末尾显示当前累计值。
- 回合名额：每名玩家每回合最多登神一只（见 §5.3）。

### 10.2 究极生物（棱彩）

回收你当前的 **T1 和 T2** 单位，每回收一个按阶级折算加成，最后获得 1 个目标兵种单位：

| 回收对象 | 加成 |
| --- | --- |
| 每个 T1 | +7% 血量、+3% 伤害 |
| 每个 T2 | +14% 攻速、+6% 射程 |

- **加成只由 T1 / T2 提供**，T3 及以上不参与折算。
- 目标池是一张独立的跨阵营名单，覆盖 T3 / T4 与部分箱子单位、超级要塞。

### 10.3 买二送一（黄金）

指定兵种，该兵种**买二送一**：每产出 / 回收 2 个，赠送 1 个。

- 与登神可以指向同一个兵种，此时赠送的那只若池内已有种子则直接转为登神层数，不占池。
- 候选会排除已被替换型符文覆盖的原形态。

### 10.4 以战养战（棱彩）

敌方**每一个单位死亡**，都会为**下回合**的你的该兵种提供增益：

| 敌方死亡单位阶级 | 提供 |
| --- | --- |
| T1 / T2 / T3 / T4 | 各 1% 的血量 / 伤害 / 攻速 / 射程（按阶级逐项递增） |

- 加成随**经济倍率**带小数，面板显示为「本回合加成：…」。
- 按兵种各成一张卡，每张卡只结算自己兵种的份数。

### 10.5 等价交换（棱彩）

取卡那一刻随机定两个兵种，组成「受益 / 受损」一对：

| 角色 | 血量 | 伤害 / 攻速 / 射程 |
| --- | --- | --- |
| 〔受益兵种〕 | **+90%** | **+25%** |
| 〔受损兵种〕 | **−90%** | **−50%** |

- 两个兵种必然不同，且只从当前未被禁用的兵种里抽。

### 10.6 元神互锁（黄金）

取卡那一刻随机定两个兵种组成「同步组」，此后**组内两个兵种的海克斯符文数值 BUFF 互相通用**：原本只作用于步兵的加成，组内另一个兵种也吃，反之亦然。

- 只同步**改变属性的数值**；赠兵 / 协议 / 召唤 / 一次性收益不同步。
- **负面数值也算数值，同样同步。**
- 护甲也按同一口径同步（伙伴兵种那侧的护甲加到这一侧，且全兵种护甲只加一次）。
- 要求至少有 2 个可用兵种。

### 10.7 质变 / 赌怪（即时奖励）

| 符文 | 稀有度 | 效果 |
| --- | --- | --- |
| 质变（银） | 白银 | 立即从筛选后的**金色**池随机授予 1 个符文 |
| 质变（金） | 黄金 | 立即从筛选后的**棱彩**池随机授予 1 个符文 |
| 赌怪 | 棱彩 | 立即获得**两个**随机符文 |

- 质变**可重复**；彩档没有质变卡，所以奖励链走到彩档自然收敛。
- 质变与赌怪**允许进入彼此的奖励池**（只挡「赌怪发赌怪」一条），所以最顺的一串是：银质变 → 金质变 → 彩赌怪 → 两张随机符文。
- 赌怪与顺手的事**互斥**。
- 奖励池沿用阵营、禁兵种与不可重复条件。

### 10.8 变形重组器 / 升级重组器

| 符文 | 稀有度 | 效果 |
| --- | --- | --- |
| 变形重组器 | 黄金 | 把当前单位池里的**全部单位**随机重组为**同一阶**的单位 |
| 升级重组器 | 棱彩 | 把当前单位池里的**全部单位**随机重组为**高一阶**的单位（T4 单位重滚为随机 T4） |

- 两张都是**本场第一次正式选择不下发**——那时单位池还空着，整体重滚等于一张空符文。
- 两张都可重复获得。

### 10.9 准备背包 / 顺手的事 / 精挑细选

| 符文 | 稀有度 | 效果 | 兑现后 |
| --- | --- | --- | --- |
| 准备背包 | 白银 | 你**下次**符文选择会整体**升一阶** | 面板标「（已生效）」 |
| 顺手的事 | 白银 | 你**下次**符文选择可以**多拿一张** | 面板标「（已生效）」 |
| 精挑细选 | 白银 | 你**后续**选择会**多一个选项**（即四选一） | — |

- 三张都**本场最后一次选择不下发**；顺手的事与赌怪互斥。
- 单次选择仍只升一阶 / 只多拿一张，不随份数变大；已是顶阶时升阶不白花（不会再消耗）。

### 10.10 回归基本功（棱彩）

按兵种展开，对指定兵种的单位分阶级处理：

| 目标单位阶级 | 血量 / 伤害 | 攻速 / 射程 |
| --- | --- | --- |
| T1 / T2 | **+90%** | **+50%** |
| T3 / T4 | **−90%** | **−50%** |

- 这是一张**双刃**卡：低阶单位大幅变强，高阶单位大幅变弱。
- 本场第一次正式选择不下发。

## 十二、术语

| 术语 | 含义 |
| --- | --- |
| 棱彩 / 黄金 / 白银 | 三档稀有度，分别对应彩 / 金 / 银色卡框 |
| 兵种展开 | 一张通用符文按 步兵 / 载具 / 飞机 / 海军 拆成四个独立候选 |
| 目标兵种 | 指定单位型符文（登神 / 究极生物 / 买二送一）自己抽定的那一个兵种 |
| 可重复 | 同一玩家可以拿到多份同一符文；多份按同族加算 |
| 回合名额 | 每回合每名玩家「只强化一只」类效果（登神 / 究极生物）共用的上限 |
| 同族加算 | 同效果多份先相加再一次性施加，不做连乘 |
| 阶级（T1~T5） | 单位的科技档位，影响抽卡权重、登神档位、究极生物折算与重组器阶位 |
